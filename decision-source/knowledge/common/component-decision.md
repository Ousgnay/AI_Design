# Component Decision Rules — 组件使用决策规则

## 组件层级决策规则

> 来源：Figma 组件库「组件-模板 - Copy」→「页签tab」
> 采集日期：2026-05-18

### 核心原则

| 规则 | 内容 |
|---|---|
| 组织层优先实例化 | 当 Figma 中已经存在语义完整、结构完整、可直接承载一个业务块的组织层组件时，优先实例化组织层，不要拆回分子或原子层重组。 |
| 分子次优先实例化 | 若不存在可覆盖目标场景的组织层，再检查分子组件；当 Figma 中已经存在语义完整、状态完整、可直接复用的分子组件时，优先实例化分子组件，不要退回到原子层重新拼装。 |
| 原子仅作构件 | `tab_c_select_02`、`tab_c_normal`、`bg_c_boxblock_14/16`、`tab_chat_select_01` 等原子/基础背景，默认视为组织层或分子组件的内部构件，而不是业务界面的首选实例化入口。 |
| 仅在必要时回退原子 | 只有当现有组织层与分子组件都无法覆盖目标场景，或明确要创建一个新的组合模式时，才允许回退到原子层拼装。 |
| 优先保留语义 | 做实例化决策时优先看“它代表什么交互语义”，而不是只看“它长得像不像”。相同视觉外观但不同语义的组件，不应互相替代。 |
| 组合关系要可追溯 | 若一个分子组件由多个原子组成，知识库中应同时记录“分子入口”和“内部依赖原子”，避免后续工作流误把内部原子当成最终产物。 |

### 已确认的历史分子层条目

- 聊天联系人条目：`黑名单`、`联系人`
- 聊天系统/聊天窗口功能按钮：`btn_context_special`、`btn_chat_control`
- 文本/社交操作按钮：`btn_social_action`
- 带业务语义的组合按钮：`btn_cost_addon`、`btn_jianzao`
- 侧边面板交互件：`btn_panel_side_collapse`

这些条目在现有 `component-spec.json` 中已经表现为带明确语义的组合组件，本次仅补充“层级认知”，不把它们降级回原子。

### 新增组织层认知

- `部队信息（他人）`
- `部队信息（他人）/部队信息（自己）`
- `部队状态`
- `部队状态栏`
- `营帐/icon`

这些条目不再只被视为“几个分子组件摆在一起的示例板”，而应视为可直接实例化的组织层模块。它们代表的是完整业务块，而不是单个交互分子。

### TAB 分子组件决策

- `一级tab`、`二级tab`、`聊天侧栏tab`、`背包tab`、`可展开tab`、`局部tab` 等，均应视为分子组件入口。
- 例如“弹窗/全屏顶部 tab”场景，如果目标就是标准双态主 tab，应优先实例化 `一级tab` 分子组件，而不是分别摆放 `tab_c_select_02` 与 `tab_c_normal` 后再手工补文本。
- 例如“局部筛选 tab 模块”场景，如果目标是完整的双项切换模块，应优先实例化 `二级tab模块` 或局部 tab 分子组件，而不是只实例化 `bg_c_boxblock_14` 或 `bg_c_boxblock_16`。

## TAB 背景

### 核心原则

| 规则 | 内容 |
|---|---|
| 选中态（select） | 深棕色 + 暗纹饰，**不可拉伸**，使用固定尺寸图片 |
| 未选中态（normal） | 米白/浅色底板，**九宫格可拉伸**，可适配不同宽度 |
| 命名规律 | `_select` / `_normal` 后缀区分状态；`_c_` 中缀表示通用组件 |

---

### 按使用场景的 Tab 组件映射

#### 1. 弹窗 / 全屏 顶部主 Tab
- **视觉特征**：选中深棕带纹饰（宽），未选中米白细金框（窄）；两 tab 并排，选中约为未选中的 3 倍宽
- **组件**：选中 → `tab_c_select_02`（275×86px，不可拉伸）；未选中 → `tab_c_normal`（86×86px，九宫格）
- **典型场景**：弹窗顶部「个人 / 同盟」「文本 / 锁甲」类切换

#### 2. HUD 图标型 Tab
- **视觉特征**：正方形等宽排列，纯图标无文字；选中深棕底+浅色图标，未选中米白底+深色图标
- **组件**：`tab_c_select_05` / `tab_c_normal_05`（32×66px 竖向小 tab）
- **典型场景**：HUD 功能区图标快捷 tab（4 个并排）

#### 3. 聊天侧栏 Tab
- **视觉特征**：色调偏冷灰（区别于暖棕体系）；选中为宽横条，未选中为正方形
- **组件**：选中 → `tab_chat_select_01`（135×60px）；未选中 → `tab_chat_normal_01`（32×32px，九宫格）
- **典型场景**：聊天面板「频道 / 好友」切换

#### 4. 二级 Tab（菱形图标型）
- **视觉特征**：45° 旋转方块（菱形）外形，图标下方带文字标签；选中填充深棕，未选中浅色轮廓
- **组件**：`btn_c_tab_select` / `btn_c_tab_deselect`（60×60px，九宫格）
- **典型场景**：功能大类切换（如「奇谋」等类目图标）

#### 5. 局部 Tab（文字型，可变宽）
- **视觉特征**：tab 宽度随文字内容变化，不固定等宽；选中深灰/棕背景，未选中较浅背景
- **组件**：`bg_c_boxblock_14`（18×58px，较宽块）/ `bg_c_boxblock_16`（12×52px，较窄块）；均为极细九宫格
- **典型场景**：面板内「当前效果 / 满级效果」「文本 / 武勋榜」

#### 6. 全屏背包 / 装备界面 Tab
- **视觉特征**：超宽横幅，左侧伴有暗色装饰性竖向背景条
- **组件**：`tab_armyadviser_select`（500×108px，不可拉伸）
- **典型场景**：全屏背包、装备、军师等界面的顶部主 tab

## 背景底板

### 按使用场景的底板组件映射

#### 7. SLG 地图行动选择浮层（竖向菱形图标组）
- **视觉特征**：3 个菱形图标纵向排列，每图标下有文字（攻占/行军/驻守）；选中填充深棕，未选中浅色
- **组件**：Bg3（47×147px 小型竖向背景条）承载整个浮层

#### 8. SLG 地图浮层 — 建造/行动提示气泡
- **视觉特征**：左侧圆形图标 + 右侧横向文字条组合，整体深棕色调
- **组件**：`Bg5`（229×66px 横向文字背景条）+ 圆形图标底板

#### 9. SLG 地图城市列表行
- **视觉特征**：「等级圆形徽章 + 城市名 + 坐标」每行信息，有常规/深色两种深度变体
- **组件**：
  - 城市标记：`pic_slgmap_city_normal` / `pic_slgmap_city_select`（54×32px，两态）
  - 大 tab 背景：`tab_slgmap_bg00/01`（555×81px）
  - 小 tab 背景：`tab_slgmap_bg02/03`（380×68px）

#### 10. SLG 地图城市信息卡片（点击 popup）
- **视觉特征**：「城市名 + 等级 + 坐标」信息条 + 操作按钮（星标/刷新）
- **组件**：`bg_slgmap_tips_bg`（32×32px，九宫格气泡底板）

#### 11. SLG 地图玩家聊天气泡
- **视觉特征**：大型圆形头像框 + 右侧浮字，叠加在地图上
- **组件**：Bg1（74×198px 大型竖向背景条）+ `pic_c_circle_bg_r68_01`（68×68px 圆形底板）

#### 12. 排行榜 / 数据列表面板
- **视觉特征**：多列标题 tab（阵营/同盟/霸业名额）+ 可展开下拉子列表，带纹理面板背景
- **组件**：`tab_c_select_02` / `tab_c_normal`（顶部 tab）+ `Bg2`（172×290px 大型九宫格面板背景）

#### 13. 侧边建筑分类列表面板
- **视觉特征**：顶部可折叠 tab（「建筑 ^」）+ 竖向建筑类型列表，带图标
- **组件**：`Bg7`（91×91px，三色变体：红/深/Default）

#### 14. 关闭按钮底板
- **视觉特征**：圆角方形关闭按钮，独立于内容区
- **组件**：`btn_c_close_bg`（58×58px）+ `Bg6`（69×68px 小圆角底板，用于图标承载）

## Toast 背景

> 来源：Figma 组件库「组件-模板」→「原子素材2 - Toast背景」
> 采集日期：2026-05-15

### 按使用场景的 Toast 组件映射

#### 15. 通知横条（全宽，通用）
- **视觉特征**：深棕米色横条，967×57px，三段九宫格可拉伸，宽度适配全屏
- **组件**：`bg_toast_宽条`（`bg/Default`，967×57px，三段九宫格）
- **典型场景**：地图行军路线信息横条（「行军路线限制：距线○○○」「每移动1格消耗1左补给」）

#### 16. 战报 / 状态通知横条（中宽，双色变体）
- **视觉特征**：606×57px 中宽横条，同尺寸双色变体；颜色对应语义，不可互换
- **组件**：`bg_战报_红`（606×57px）/ `bg_战报_黑`（606×57px）；均为三段九宫格
- **颜色选取规则**：红色 = 战斗/危险/倒计时；黑色 = 成功/中性/完成
- **典型场景**：红→「X[渐军 (99,945)] 00:52:56 后开始」；黑→「已成功补充兵力」

#### 17. Toast 弹出气泡背景（窄版，固定尺寸）
- **视觉特征**：461×66px，渐变装饰背景，不可拉伸；与文字叠加使用
- **组件**：`pic_c_toast_bg`（461×66px，固定尺寸图片）
- **典型场景**：操作结果 Toast 弹出（文字内容区上方的装饰性背景）

## TIP 背景

> 来源：Figma 组件库「组件-模板」→「原子素材2 - TIP背景」
> 采集日期：2026-05-15

### 按使用场景的 TIP 组件映射

#### 18. TIP 面板渐变装饰条（竖向窄条）
- **视觉特征**：60×96px 竖向渐变条，九宫格；渐变从深到透明，用作 TIP 面板左侧或角落装饰
- **组件**：`bg_c_tips_gradient`（60×96px，九宫格）
- **典型场景**：快捷操作 TIP 浮层（「迁城 / 加入 / 战力上限」等操作列表面板）左侧装饰条

#### 19. TIP 背景横条（短版，固定）
- **视觉特征**：318×53px，单行横向背景条；比 Toast 宽条更细窄，不可拉伸
- **组件**：`bg_tip_短条`（节点 6544:27600，318×53px，固定尺寸）
- **典型场景**：「✓ 多选」等单行 TIP 提示横条

#### 20. SLG 趋势标题背景（阵营语义，四色系列）
- **视觉特征**：437×63px 横向宽条，4 种固定图案，颜色与阵营强绑定
- **阵营颜色规则**（不可互换）：

| 变体 | 阵营 | 颜色 | nodeId |
|---|---|---|---|
| `pic_slg_trend_bg01` | 我方阵营 | 绿色 | 6488:12092 |
| `pic_slg_trend_bg02` | 友方阵营 | 黄色 | 6488:12094 |
| `pic_slg_trend_bg03` | 敌方阵营 | 红色 | 6488:12096 |
| `pic_slg_trend_bg04` | NPC阵营 | 褐色 | 6488:12098 |

- **典型场景**：趋势/等级数据标题横条（「敌军不弱 [52134 × 2]」—— 目标为敌方，取 bg03）
- **关键决策**：必须根据目标单位的阵营关系选取对应变体

## 标题背景

> 来源：Figma 组件库「组件-模板」→「原子素材3 - 标题背景」
> 采集日期：2026-05-15

### 按使用场景的标题组件映射

#### 23. 全屏大标题栏
- **视觉特征**：870×100px 宽幅横幅，纹理装饰丰富；固定尺寸图片
- **组件**：`bg_c_biaotidi_1`（870×100px，固定图片）
- **典型场景**：全屏面板/弹窗顶部大型标题背景（配大号标题文字）

#### 24. 中型标题栏（贵族/次级面板）
- **视觉特征**：520×74px，比大标题栏更窄；固定图片
- **组件**：`pic_aristocracy_title_bg`（520×74px，固定图片）
- **典型场景**：贵族功能、次级面板等中型标题背景

#### 25. 小标题装饰方块（boxblock_12 / boxblock_13）
- **视觉特征**：约 50×50px 正方形，九宫格；12（52px）与 13（50px）视觉效果略有差异，使用场景相同
- **组件**：`bg_c_boxblock_12`（52×52px）/ `bg_c_boxblock_13`（50×50px）；均为九宫格
- **典型场景**：段落小标题左侧装饰方块，与标题文字并排使用

#### 26. 通用段落标题背景单元
- **视觉特征**：16×16px 极小九宫格，可拉伸为任意宽度标题背景条

## 按钮系统设计规范

> 来源：Figma「通用按钮」(1928:3190) — **含明文使用规则，权威性最高**
> 采集日期：2026-05-15

### 按钮层级体系

| 层级 | 名称 | 每屏数量上限 | 核心约束 |
|---|---|---|---|
| 0 | 大尺寸特殊按钮 | **最多 1 个** | 强美术表现+意图单一；严禁用于列表/弹窗/高频区 |
| 1 | 一级按钮 | **1~2 个** | 核心操作/游戏推进/获得收益 |
| 2 | 二级按钮 | 不限 | 次优先级必要操作；可拉伸宽度 |
| 3 | 功能性按钮 | 不限 | 辅助操作入口（bg_c_boxblock_07 系列）|

**关键决策**：选按钮层级时先判断该操作在界面中的重要程度，再匹配层级，而不是按视觉喜好选。

---

### 按钮状态规则

#### 置灰（禁用）
- 用于：功能未开放、次数/资源不足等限制状态
- **仍可点击**，点击后弹 Toast 反馈

#### 消耗-购买
- 货币不足时消耗数字显示**红色**
- 若有折扣价，仅判断**当前售价**是否不足，原价始终以标准色+删除线展示

#### 消耗-行为（非购买消耗）
- 按钮文本 = 操作名称（如「确认」）
- 数量/消耗显示在按钮**上方居中**
- 货币不足→红色；货币充足→绿色
