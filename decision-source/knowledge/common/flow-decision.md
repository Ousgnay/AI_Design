# Flow Decision Rules — 界面流程与链路规则

> 来源：文件分类约定预留入口
> 创建日期：2026-05-19

## 定位

本文件用于记录 `flow` 类知识：

- 页面之间的跳转关系
- 功能入口与出口
- 用户操作链路
- 状态流转顺序
- 任务步骤、前后置依赖与中断恢复逻辑

## 与其他文件的边界

- `component-*` 只处理组件本身及组件实例化规则
- `layout-*` 只处理页面骨架、分区结构与界面分类
- `tokens-*` 只处理样式 token 与使用规范
- `flow-decision.md` 处理“界面如何串起来、用户如何走完一条链路”

## 当前规则

- 若用户提供的是页面流程图、操作路径图、页面跳转关系图、任务步骤图或状态机式界面链路，应优先写入本文件
- 若某条知识同时涉及 layout 与 flow：
  - 页面骨架归 `layout-*`
  - 页面之间的进入、退出、跳转、分支、回流关系归 `flow-decision.md`

## 后续扩展方向

后续可在本文件中继续补充：

- 主流程 / 支线流程 / 异常流程分类
- 页面入口优先级
- 弹窗插入时机与阻断规则
- 多步骤任务的状态推进模型
- 页面返回栈与关闭策略
