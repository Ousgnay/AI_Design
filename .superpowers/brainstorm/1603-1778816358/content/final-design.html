③ 核心数据流（环节1→4）

环节1
策划MD（必选）+ 竞品拆解MD（可选）→ 喂给 ia-generate
环节2
ia-generate 读 knowledge/（只读）+ learnings/（只读）→ 推理产出 IA 结构化文档.md
决策层：流程推理 / 界面容器 / 布局区划 / 状态枚举 / Component选择
环节3
用户审阅 IA 文档.md → 确认后手动触发 官方 figma-generate-design → 产出 Figma 界面
能复用的 component 严格引用，不能复用的按 token 凭空绘制
环节4
self-improving：人类反馈 → AI 复盘归纳 bad case → 写 learnings/pending/ → 人工审批 → 蒸馏更新 knowledge/ → learnings 清除
同时由 ux-collect 持续采集新规则补充 knowledge/
