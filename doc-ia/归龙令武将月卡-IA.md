## 1. 业务逻辑摘要

面向离开30天+的回归用户，提供一次性「归龙令武将月卡」（30元/30天）：赠免费体验期（1\~3天）→ 引导付费激活 → 使用200+武将（含5选2高级将）→ 到期后个性化折扣推送，引导购买永久武将。核心诉求是降低回归门槛、建立武将情感锚点（熟练度/胜率数据）、实现到期付费转化。

---

## 2. 用户流程

**主流程（免费体验 → 激活）：**

```
回归用户登录（离线30天+）
  ↓
【欢迎弹窗】展示权益 + 免费体验N天
  ↓ 点击「立即体验」
【武将选择弹窗】高级武将5选2
  ↓ 选满2个 → 点击「确认」
【激活成功弹窗】
  ↓
  ├─→「立即对局」→ 进入游戏
  └─→「查看月卡」→【月卡主界面】
```

**付费购买流程（体验到期 → 购买）：**

```
免费体验到期推送 / 主动点击归龙令icon
  ↓
【月卡主界面】或直接弹购买提醒
  ↓ 点击「立即购买」
【购买确认弹窗】价格 + 支付方式选择
  ↓ 确认支付
【武将选择弹窗】（首次购买需重新选将）
  ↓
【激活成功弹窗】→ 进入游戏
```

**到期转化流程：**

```
月卡到期（到期前7/3/1天个性化推送）
  ↓ 到期后自动触发
【到期转化弹窗】个性化推荐 + 48h折扣倒计时
  ↓ 点击「立即购买」
【购买确认弹窗】→ 支付 → 获得永久武将 + 转化礼包
```

**更换武将分支：**

```
【月卡主界面】点击「更换武将」
  ↓ 若本月免费次数已用完 → 提示消耗30元宝
【武将选择弹窗】更换模式（24h冷却期过后可操作）
```

### 界面 6：到期转化弹窗

**容器**：居中弹窗（Modal）
**决策依据**：策划案§1.7明确"到期后48小时是核心转化窗口，弹窗必须精准触达，不能被折叠在系统消息里"；居中Modal打断感最强，打破用户惯性；限时决策场景，居中Modal配合倒计时形成紧迫感

#### 布局区划

| 区域 | 内容 | 信息权重 |
|---|---|---|
| 顶部区 | 标题"归龙令已到期" + 折扣限时标语 + 48h倒计时组件 | 高 |
| 主内容区-情感锚点 | 月卡期间数据回顾："你使用了X个武将，最爱XXX，胜率YY%"（让用户感知情感连接，策划§1.7核心诉求） | 高 |

`component-spec.json` 中无武将卡片类组件记录。策划案§C.1提到"武将系统通用卡片组件"，说明已有对应组件，但尚未被 `/ux-collect` 采集。

### 5.4 武将选择弹窗竖横屏适配

## 6. 下游提示（给官方 Figma Skill 包）

### 核心设计意图

本系统构建"探索→体验→情感锚点→转化"心理路径：

1. **欢迎弹窗**：低门槛触达，视觉以「令」字标识为核心，暖橙金色调，快速建立品牌识别
2. **武将选择弹窗（最重要）**：这是全功能的灵魂界面。5个高级武将大图+品质光效必须足够震撼，建立"我选了这个将"的拥有感与稀有感。高级武将卡尺寸应明显大于普通武将卡
3. **月卡主界面**：高级武将是绝对主角，数据（熟练度/胜率）是情感锚点的载体，到期状态需醒目但不干扰正常浏览
4. **到期转化弹窗**：情感打动优先于利益驱动。数据回顾区是关键设计点，让用户感受"我已经和这个将建立了羁绊"，然后折扣CTA水到渠成

| 2 | get_design_context(nodeId) | 通过本 IA 中已记录的 nodeId 直接定位组件，无需重新检索 |
| 3 | figma-use / use_figma | 根据 IA 布局搭建各界面 Frame，优先复用已收录组件，新建组件单独建立 |
